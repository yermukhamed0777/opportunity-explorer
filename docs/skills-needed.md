# Skills to Develop

These are suggested routes for building competence and a portfolio. They are not universal employer requirements, degree curricula or promises of a job. Course pages were checked on 11 November 2026. Course access, certificate fees and institutional licences can change.

| Path                       | Technical foundation                                                                | Tools and practical techniques                                                      | Example evidence                                                                                      |
| -------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Materials / semiconductors | Structure–property relationships, thermodynamics, kinetics, experimental statistics | Python, Jupyter, spreadsheets, supervised microscopy and diffraction interpretation | A reproducible analysis connecting processing to a measured property, including units and uncertainty |
| Software / AI              | Programming, algorithms, SQL, model evaluation, testing                             | Python, Git, databases, testing tools                                               | A deployed search app with a baseline, held-out evaluation and tests                                  |
| Mechanical / robotics      | Mechanics, load paths, CAD, tolerances, controls                                    | CAD assemblies, technical drawings, Python, supervised prototyping                  | A gripper design with calculations, drawings, bill of materials and test plan                         |
| Physics / research         | Mathematics, numerical models, measurement uncertainty                              | Python, plotting, curve fitting, laboratory notebooks                               | A cited dataset, fitted physical model, residuals and limits                                          |
| Chemistry / life sciences  | Stoichiometry, calibration, controls, lab safety                                    | Calibration spreadsheets, Python, supervised spectroscopy                           | A calibration report with controls, uncertainty and reproducible calculations                         |
| Business / analytics       | Financial statements, spreadsheet modeling, statistics                              | Spreadsheets, visualizations, public financial reports                              | A transparent spreadsheet and concise decision memo                                                   |

Start with a small fundamental exercise, build an intermediate analysis or model, then produce an advanced project that explains assumptions, checks and limitations. Writing, evidence-based reasoning, teamwork and project planning matter in every route. Certificates are optional evidence of study; practical work remains necessary.
